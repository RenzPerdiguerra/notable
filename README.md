# notable

Intelligent Note-taking App

This app is created to allow AI assistance or intervention during note-taking, creation of quick summaries and answering questions. This app is inspired by AI chatbots, generative AI assistants, or large language models (LLMs) and Obsidian Note Taking App.

This app is part of preparation for developing skills in software development focusing on the full-stack development, authentication (JWT/OAuth), caching, deployment and applying AI Technologies. 

Prerequisites:
Python 3.14.0

Framework
FastAPI

Notable Libraries
SQLAlchemy
Alembic
JWT
Oauth
React

AI Technology
